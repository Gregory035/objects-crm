# Объекты и задачи

Мини-CRM строительной команды: React + TypeScript + Supabase.

## Запуск

Node.js 22+. Выполните `npm ci`, скопируйте `.env.example` в `.env.local` и задайте URL Supabase и publishable key. `npm run dev` запускает приложение, `npm run build` проверяет TypeScript и собирает production-версию.

## База

SQL в `supabase/migrations` применяется по порядку к новому проекту Supabase. Отключите Allow new users to sign up в Authentication → Sign In / Providers. Создайте пользователей через Authentication → Users, затем добавьте строки в `public.profiles` с соответствующими UUID, именами и ролями `manager`/`worker`. Роли задаются в profiles; менять их через приложение нельзя.

## Права доступа

Доступ к строкам ограничен RLS. Переходы статусов проверяет триггер `validate_task`, историю записывает `record_status`. У клиента нет прав записи в `task_history` и изменения `profiles`.

## Решения и допущения

- Постановщики видят все объекты и задачи общей команды.
- Удаление мягкое: записи скрываются из рабочих списков, история физически сохраняется. Восстановление в текущей версии не реализовано: для него нужна отдельная административная процедура.
- Объект можно удалить только после удаления его задач; правило проверяется базой.
- Смена исполнителя и объекта не сбрасывает статус. Изменение данных и статуса выполняется отдельными операциями.
- Принятая задача не возвращается в работу: такой переход отсутствует в ТЗ.
- История включает создание задачи. Комментарий необязателен при приёмке и обязателен при возврате.
- Пользователи создаются администратором Supabase; управления сотрудниками и открытой регистрации в приложении нет.
- Обновление данных — при действиях пользователя и кнопкой «Обновить», без realtime.
- Данные демонстрационные; названия и адреса условные.

## Размещение

GitHub Pages, автоматическая сборка через GitHub Actions. Используется hash-навигация, поэтому ссылки на карточки работают без серверного маршрутизатора. Для подключения используется publishable key. Секретных ключей в репозитории нет.
